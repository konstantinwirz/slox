# LOX interpreter

An implementation of Lox interpreter as defined [here](https://craftinginterpreters.com/).

Work in progress...

## Testing
The test suite is in that [repo](https://github.com/munificent/craftinginterpreters), clone it. Also you are gonna need a dart installation (v2 not v3).

Run tests
```shell
make test-all
```

Executing tests for single chapters is possible too, have a look at the [Makefile](Makefile)
